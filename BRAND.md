# Upbeat RGV — working brand assets

These vectors are raster-derived working traces, not verified original master artwork. Review the contact sheet with the brand owner before production use. Source references were supplied locally; original post URLs and exact publication dates were not provided.

## Marks

1. **UB triangle monogram** — outlined inverted triangle with angular inner strokes. `assets/logo-1.svg`; source `refs/ig-profile-ub.jpg`, with stage context in `refs/fb-cover-1-lasers.jpg`. The profile image is low resolution; line widths and corners are approximate, not exact master geometry.
2. **Boxed Upbeat / RGV** — bold uppercase wordmark within a broken rectangular frame. `assets/logo-2.svg`; source `refs/fb-profile-upbeat-box.jpg`. Small letters and edge details are approximations.
3. **Upbeat Entertainment brush wordmark** — expressive brush lettering over a smaller subtitle. `assets/logo-3.svg`; source `refs/fb-cover-5.jpg`. Thresholding removes background texture and some brush-edge detail.

`assets/logos-sheet.png` compares each local reference crop on the left with its trace on the right. All three SVGs use white filled paths, no raster images, and a viewBox. Validate extrusion, counters, and small isolated parts in the actual Three.js scene before use.

## Visual direction

Observed in supplied references: white marks on black; blue-violet, purple, and cyan-white event lasers. The following are **proposed creative colors**, not verified official brand values:

| Role | Proposed value |
|---|---|
| Void | `#08080c` |
| White | `#f5f5f5` |
| Chrome | `#b9c4d1` |
| Laser violet | `#683bfa` |
| Laser cyan | `#74eafa` |
| Event magenta | `#d333a6` |

Use a dark, restrained studio interface. Let event footage, narrow laser beams, and readable logo silhouettes carry the color. Use reflective chrome sparingly, with controlled highlights rather than a full-frame glow. For BPM-synced motion, offer bar-length loops and independent intensity controls; avoid flashing that obscures the mark. These are art-direction proposals, not claims about existing brand standards.
